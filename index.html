Tes clés · 1/4

Ta clé Groq

Une clé, c'est un long code qui permet à Amine d'utiliser ton compte.

Ouvre une note vide sur ton ordinateur : tu y colleras tes clés le temps de l'installation, puis tu la supprimeras.
  1. Crée ton compte (gratuit) si on te le demande.
  2. Clique sur Create API Key, écris Amine comme nom, puis valide.
  3. Copie la clé affichée (elle commence par gsk_) et colle-la dans ta note.

Tes clés · 2/4

Ta clé ElevenLabs

Il te faut l'abonnement Starter au minimum (pour le clonage de voix).

Clique sur Create Key. Une fenêtre s'ouvre à droite :

  1. Dans Name, écris Amine.
  2. Clique sur l'interrupteur Restrict Key pour l'éteindre.
  3. Clique sur Create Key, puis copie la clé (elle commence par sk_) dans ta note.
N'oublie pas d'éteindre Restrict Key : sinon la clé ne marchera pour rien.
Ouvrir ElevenLabs
Tes clés · 3/4

Ta clé Replicate

Replicate sépare la voix d'origine de la musique : Amine garde la musique de la pub et pose la nouvelle voix par-dessus.

  1. Écris Amine dans la case, puis clique sur Create token.
  2. Copie le jeton (il commence par r8_) dans ta note.
  3. Clique sur Billing et ajoute ta carte : sans carte, la clé ne marche pas (c’est presque gratuit à l’usage).
Ouvrir Replicate
Tes clés · 4/4

Tes clés Vmake

Il te faut l'abonnement Plus au minimum : c'est obligatoire pour l'API.

1. Sur Vmake, clique sur l'onglet API Keys en haut (connecte-toi si on te le demande) :

2. Tu arrives sur la page de tes clés :

  1. Pas encore de clé dans le tableau ? Clique sur Create New Key (repère 1).
  2. Clique sur le bouton copier à droite de l'API Key (repère 2), puis colle-la dans ta note en écrivant devant : API Key :
  3. Clique sur le bouton copier à droite de la Secret Access Key (repère 3), puis colle-la dans ta note en écrivant devant : Secret :
La Secret Access Key est cachée par des étoiles ********. Après l'avoir collée, vérifie dans ta note que ce n'est pas des étoiles : sinon, clique d'abord sur l'œil barré pour l'afficher, puis recopie-la.

Ensuite, tout en bas sous la zone de message :

  1. Clique sur le bouton avec le petit nuage.
  2. Clique sur Nouvel environnement.

Ton atelier · 3/3

Le démarrage et les réglages

Fais défiler la fenêtre vers le bas :

1. Dans « Script de configuration », colle :

#!/bin/bash
for d in /home/user/*/; do [ -f "$d/amine/SKILL.md" ] && bash "$d/setup.sh"; done

2. Dans « Variables d'environnement », colle :

GROQ_API_KEY=cloud
ELEVENLABS_API_KEY=cloud
REPLICATE_API_TOKEN=cloud
MT_AK=COLLE_ICI_TON_ACCESS_KEY_VMAKE
MT_SK=COLLE_ICI_TON_SECRET_KEY_VMAKE
BASH_DEFAULT_TIMEOUT_MS=600000
BASH_MAX_TIMEOUT_MS=1800000
Dans ce qui est collé, remplace les deux textes en majuscules par tes clés Vmake : l'API Key après MT_AK=, la Secret Access Key après MT_SK=, sans espace.

3. Clique sur Ajouter un environnement en bas (ou Enregistrer les modifications).

Le coffre · 1/3

Range ta clé Groq

Le coffre (« Secrets réseau ») garde tes clés à l'abri : Claude peut s'en servir, mais jamais les lire.

Rouvre ton environnement (bouton nuage → Cloud → passe la souris sur Amine → roue dentée), puis clique sur Ajouter un secret :

  1. Nom : Groq
  2. Sites web autorisés : tape api.groq.com puis appuie sur Entrée.
  3. Valeur : colle ta clé Groq (laisse Authorization et Bearer tels quels).
  4. Clique sur Ajouter.
Le coffre · 2/3

Range ta clé ElevenLabs

Clique encore sur Ajouter un secret. Attention, celui-ci a deux cases différentes (3 et 4) :

  1. Nom : ElevenLabs
  2. Sites web autorisés : tape api.elevenlabs.io puis Entrée.
  3. Sous « En-têtes personnalisés », remplace Authorization par xi-api-key.
  4. Efface le mot Bearer : la case Préfixe doit être vide.
  5. Valeur : colle ta clé ElevenLabs.
  6. Clique sur Ajouter.
Le coffre · 3/3

Range ta clé Replicate

  4. Clique sur Ajouter, puis sur Enregistrer les modifications.

Un souci ?

Claude dit qu'une variable est « MANQUANTE »

Revois l'écran « Les réglages » de ton atelier, puis démarre une nouvelle session.

Erreur 401 ou « invalid api key »

La clé de ce service est fausse. Supprime son secret dans le coffre et ajoute-le à nouveau. ElevenLabs : la clé commence par sk_.

Erreur 402, « insufficient credit » ou quota

Le compte de ce service n'a plus de crédit : recharge-le.

Claude ne voit pas mon dépôt

Refais l'écran « Ouvre Claude et crée ton environnement » (bouton 2 : installer Claude sur GitHub, avec All repositories).

Ma vidéo ne s'ajoute pas (trop lourde)

Réduis-la avant (par exemple avec HandBrake, gratuit), ou demande à ton formateur.
