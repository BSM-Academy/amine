Guide d'installation

Installe AdCloner en 20 minutes

Tu vas brancher AdCloner sur ton compte Claude. Ensuite, pour traduire une pub, tu n'auras plus qu'à écrire une phrase. Rien ne s'installe sur ton ordinateur : tout tourne dans le cloud de Claude.

Sert à créer tes liens personnels plus bas.

Ton avancement est gardé sur ce navigateur : tu peux fermer la page et revenir. Cette page ne te demandera jamais tes clés.

0 étape sur 8
1

Avant de commencer

2 min · sur ordinateur

Fais l'installation sur un ordinateur (pas sur téléphone). Ensuite, tu pourras lancer des vidéos depuis ton téléphone aussi.

AdCloner utilise 5 services. Tu as un compte à toi sur chacun, et tu paies seulement ce que tu consommes :

Claude ProLe cerveau. Abonnement Pro ou Max obligatoire.
ElevenLabsLa voix. Abonnement Starter minimum (clonage de voix).
VmakeEfface le texte à l'écran. Abonnement Plus minimum pour l'API.
ReplicateSépare voix et musique. Quelques centimes par vidéo.
GroqTranscrit la voix. Gratuit.
Ouvre une note vide sur ton ordinateur (Notes, Bloc-notes) : tu y colleras tes clés au fur et à mesure, le temps de l'installation. Tu la supprimeras à la fin.
2

Ton compte GitHub et l'accès à AdCloner

5 min · puis attendre l'invitation

GitHub, c'est là où vit AdCloner, et là où tu retrouveras tes vidéos finies.

  1. Crée un compte gratuit sur github.com/signup (si tu en as déjà un, garde-le).
  2. Écris ton pseudo GitHub dans la case en haut de cette page.
  3. Envoie ton pseudo à ton formateur. Il t'invite sur AdCloner.
  4. Tu reçois un e-mail de GitHub : clique sur View invitation puis Accept invitation.
3

Crée ta copie d'AdCloner

1 min

Tu crées ta propre copie (un « fork ») : c'est ton AdCloner à toi, où arriveront tes vidéos.

Créer ma copie sur GitHub
  1. Sur la page qui s'ouvre, ne change pas le nom (adcloner-eleves).
  2. Clique sur Create fork.
  3. Tu arrives sur ton dépôt ton-pseudo/adcloner-eleves. Garde cet onglet ouvert.
4

Récupère tes 5 clés

8 min

Une clé, c'est un long code qui permet à AdCloner d'utiliser ton compte. Pour chaque service : crée un compte, puis copie la clé dans ta note.

ServiceOù trouver la cléÀ quoi elle ressemble
Groqconsole.groq.com/keys → Create API Keygsk_…
ElevenLabselevenlabs.io → Settings → API Keys → Create API Keysk_…
Replicatereplicate.com/account/api-tokensr8_…
Vmake (2 clés)vmake.ai/developers → API KeyAccess Key + Secret Key
ElevenLabs : copie bien la clé (elle commence par sk_), pas son identifiant. C'est l'erreur la plus fréquente.
Crédit : une clé ne marche que si le compte a du crédit. Sur Replicate, ajoute une carte dans Billing. Sur ElevenLabs et Vmake, prends l'abonnement indiqué à l'étape 1.
5

Connecte Claude à GitHub

2 min
  1. Ouvre claude.ai/code et connecte-toi.
  2. Claude te propose de connecter GitHub : accepte.
  3. GitHub te demande où installer l'application Claude : choisis Only select repositories, puis sélectionne adcloner-eleves. Clique sur Install.
Déjà connecté à GitHub sur Claude ? Ajoute simplement adcloner-eleves dans GitHub → Settings → Applications → Claude → Configure.
6

Crée ton environnement AdCloner

4 min

L'environnement, c'est l'atelier où Claude travaille : quels sites il peut joindre, et ce qu'il prépare au démarrage.

  1. Sur claude.ai/code, juste au-dessus de la zone de message, clique sur l'icône en forme de nuage (elle affiche « Default »).
  2. Clique sur Cloud, puis Add cloud environment.
  3. Name : écris AdCloner.
  4. Network access : choisis Custom. Dans Allowed domains, colle : 
    api.groq.com
api.elevenlabs.io
api.replicate.com
replicate.delivery
*.replicate.delivery
*.vmake.ai
*.aliyuncs.com
*.fbcdn.net
medias.trendtrack.io
    Puis coche la case Also include default list of common package managers.
  5. Environment variables : colle ce bloc, puis remplace les deux lignes Vmake par tes clés Vmake (Access Key après MT_AK=, Secret Key après MT_SK=, sans espace) : 
    GROQ_API_KEY=cloud
ELEVENLABS_API_KEY=cloud
REPLICATE_API_TOKEN=cloud
MT_AK=COLLE_ICI_TON_ACCESS_KEY_VMAKE
MT_SK=COLLE_ICI_TON_SECRET_KEY_VMAKE
ADCLONER_WHISPER=groq
ADCLONER_DEMUCS=replicate
BASH_DEFAULT_TIMEOUT_MS=600000
BASH_MAX_TIMEOUT_MS=1800000
    Les trois =cloud sont normaux : tes vraies clés Groq, ElevenLabs et Replicate vont dans un coffre à l'étape suivante.
  6. Setup script : colle : 
    #!/bin/bash
for d in /home/user/*/; do [ -f "$d/adcloner/SKILL.md" ] && bash "$d/setup.sh"; done
  7. Clique sur Create environment.
7

Range tes 3 clés dans le coffre

3 min

Les « secrets réseau » gardent tes clés hors de portée : Claude peut s'en servir, mais ne peut pas les lire.

  1. Rouvre le sélecteur (icône nuage) → Cloud, survole AdCloner et clique sur la roue dentée.
  2. Dans Network secrets, clique sur Add secret. Laisse Secret type sur Bearer.
  3. Remplis le formulaire avec la première ligne du tableau, clique sur Add. Recommence pour les deux autres lignes.
NameAllowed websitesHeader NamePrefixValue
Groqapi.groq.comAuthorizationBearerta clé Groq
ElevenLabsapi.elevenlabs.ioxi-api-keyvide (efface Bearer)ta clé ElevenLabs
Replicateapi.replicate.comAuthorizationBearerta clé Replicate
ElevenLabs est différent : remplace Authorization par xi-api-key et efface le mot Bearer du préfixe.

Une fois les 3 secrets ajoutés, supprime ta note : tes clés sont à l'abri.

8

Le test final

2 min
  1. Sur claude.ai/code, choisis le dépôt adcloner-eleves et l'environnement AdCloner (icône nuage).
  2. Écris : 
    Vérifie mon installation AdCloner.
  3. Claude doit répondre que tout est ok. Sinon, il te dit quelle étape refaire.

Traduire une pub au quotidien

  1. Dépose ta vidéo dans ton dépôt : ouvre le dossier sources de ton dépôt → Add file → Upload files → Commit changes (25 Mo maximum).
  2. Sur claude.ai/code (dépôt adcloner-eleves, environnement AdCloner), écris par exemple : 
    Traduis la vidéo sources/ma-pub.mp4 en français. Ma marque : …, mon produit : …, mon site : …
  3. Claude t'annonce le coût (crédits Vmake, caractères ElevenLabs) et attend ton ok.
  4. Environ 15 minutes plus tard, il te donne un lien : clique dessus, puis sur le bouton de téléchargement (flèche vers le bas). Tu peux fermer l'ordinateur pendant ce temps : ça continue de tourner.
Mettre à jour AdCloner : quand ton formateur annonce une nouvelle version, va sur la page de ton dépôt GitHub et clique sur Sync fork → Update branch.
Bon à savoir : tes vidéos finies sont rangées dans la branche livraisons de ton dépôt. Ton formateur peut les voir, pour t'aider à progresser et améliorer AdCloner. Télécharge-les au fur et à mesure : si ton accès à AdCloner se termine, ta copie est supprimée.

Problèmes fréquents

Claude dit qu'une variable est « MANQUANTE »

Rouvre ton environnement (roue dentée) et vérifie le bloc Environment variables de l'étape 6. Puis démarre une nouvelle session : une session déjà ouverte garde les anciennes valeurs.

Erreur 401 ou « invalid api key »

La clé du service cité est fausse ou mal collée. Supprime le secret (étape 7) et ajoute-le à nouveau avec la bonne clé. Pour ElevenLabs, vérifie qu'elle commence par sk_.

Erreur 402, « insufficient credit » ou quota

Le compte du service n'a plus de crédit. Recharge-le (Replicate : Billing ; ElevenLabs et Vmake : ton abonnement).

Claude ne voit pas mon dépôt adcloner-eleves

Refais l'étape 5 : l'application Claude doit être installée sur adcloner-eleves dans GitHub.

Ma vidéo fait plus de 25 Mo

Réduis-la avant de la déposer (par exemple avec HandBrake, gratuit), ou demande à ton formateur.
