AdCloner
Installation

On installe AdCloner ensemble

Une petite étape à la fois, environ 20 minutes en tout. Rien ne s'installe sur ton ordinateur : tout tourne dans le cloud de Claude.

Comment tu t'appelles ?

Ton avancement est gardé sur ce navigateur : tu peux fermer la page et revenir plus tard.

Avant de commencer

tu auras besoin de 5 services

Un compte à toi sur chacun. Tu paies seulement ce que tu utilises.

Claude Prole cerveau (Pro ou Max)
ElevenLabsla voix (Starter minimum)
Vmakeefface le texte (Plus minimum)
Replicatesépare la voix de la musique (centimes)
Groqla transcription, gratuit

Fais l'installation sur un ordinateur. Après, tu pourras aussi lancer des vidéos depuis ton téléphone.

GitHub

Crée ton compte GitHub

C'est là que vit AdCloner, et là que tu retrouveras tes vidéos finies.

Créer mon compte GitHub

Tu en as déjà un ? Garde-le et clique sur « C'est fait ».

GitHub

Demande ton accès

Tape le code d'accès donné dans ta formation :

Demander mon accès
  1. Sur la page GitHub qui s'ouvre, clique sur Create (ne change rien).
  2. Moins d'une minute après, tu reçois un e-mail de GitHub : clique sur View invitation, puis Accept invitation.

Pas d'e-mail après 2 minutes ? Ouvre ta page d'invitation. Message « code incorrect » sur GitHub ? Vérifie le code et recommence.

GitHub

Crée ta copie d'AdCloner

C'est ton AdCloner à toi : tes vidéos arriveront dedans.

Créer ma copie

Sur la page qui s'ouvre, ne change pas le nom et clique sur Create fork.

Tes clés · 1/4

Ta clé Groq

Une clé, c'est un long code qui permet à AdCloner d'utiliser ton compte.

Ouvre une note vide sur ton ordinateur : tu y colleras tes clés le temps de l'installation, puis tu la supprimeras.
Ouvrir Groq

Crée un compte (gratuit), clique sur Create API Key, copie la clé dans ta note. Elle commence par gsk_.

Tes clés · 2/4

Ta clé ElevenLabs

Prends l'abonnement Starter au minimum (il faut le clonage de voix).

Ouvrir ElevenLabs

Clique sur Create API Key, copie la clé dans ta note.

Copie bien la clé (elle commence par sk_), pas son identifiant. C'est l'erreur la plus fréquente.
Tes clés · 3/4

Ta clé Replicate

Replicate sépare la voix d'origine de la musique : AdCloner garde la musique et le son de la pub, et pose la nouvelle voix par-dessus.

Ouvrir Replicate

Crée un compte, copie le token dans ta note. Il commence par r8_.

Ajoute une carte dans Billing : sans crédit, la clé ne marche pas. Compte quelques centimes par vidéo.
Tes clés · 4/4

Tes clés Vmake

Prends l'abonnement Plus au minimum : c'est obligatoire pour l'API.

Ouvrir Vmake

Dans API Key, copie les deux clés dans ta note : Access Key et Secret Key.

Claude

Connecte Claude à GitHub

Ouvrir claude.ai/code
  1. Claude te propose de connecter GitHub : accepte.
  2. Choisis Only select repositories, sélectionne adcloner-eleves, puis Install.

Déjà connecté ? Ajoute adcloner-eleves dans GitHub → Applications → Claude → Configure.

Ton atelier · 1/4

Crée ton environnement

L'environnement, c'est l'atelier où Claude travaille.

  1. Sur claude.ai/code, au-dessus de la zone de message, clique sur l'icône nuage (elle affiche « Default »).
  2. Clique sur Cloud, puis Add cloud environment.
  3. Dans Name, écris AdCloner.

Garde la fenêtre ouverte : on la remplit dans les 3 écrans suivants.

Ton atelier · 3/4

Les réglages

Dans Environment variables, colle ce bloc :

GROQ_API_KEY=cloud
ELEVENLABS_API_KEY=cloud
REPLICATE_API_TOKEN=cloud
MT_AK=COLLE_ICI_TON_ACCESS_KEY_VMAKE
MT_SK=COLLE_ICI_TON_SECRET_KEY_VMAKE
ADCLONER_WHISPER=groq
ADCLONER_DEMUCS=replicate
BASH_DEFAULT_TIMEOUT_MS=600000
BASH_MAX_TIMEOUT_MS=1800000
Remplace les deux textes en majuscules par tes clés Vmake (Access Key, puis Secret Key), sans espace après le =.

Les =cloud sont normaux : tes autres clés vont dans un coffre juste après.

Ton atelier · 4/4

Le démarrage

Dans Setup script, colle :

#!/bin/bash
for d in /home/user/*/; do [ -f "$d/adcloner/SKILL.md" ] && bash "$d/setup.sh"; done

Puis clique sur Create environment. 🎉

Le coffre · 1/3

Range ta clé Groq

Le coffre (« secrets ») garde tes clés à l'abri : Claude peut s'en servir, mais pas les lire.

  1. Rouvre l'icône nuage → Cloud, survole AdCloner, clique sur la roue dentée.
  2. Dans Network secrets, clique sur Add secret et remplis :
NameGroq
Allowed websitesapi.groq.com
Header NameAuthorization
PrefixBearer
Valueta clé Groq

Clique sur Add.

Le coffre · 2/3

Range ta clé ElevenLabs

Add secret à nouveau :

NameElevenLabs
Allowed websitesapi.elevenlabs.io
Header Namexi-api-key
Prefixvide
Valueta clé ElevenLabs
Ici c'est différent : remplace Authorization par xi-api-key, et efface le mot Bearer.

Range ta clé Replicate

Add secret une dernière fois :

NameReplicate
Allowed websitesapi.replicate.com
Header NameAuthorization
PrefixBearer
Valueta clé Replicate

Tes clés sont à l'abri : supprime ta note.

Dernière étape

Le test

  1. Sur claude.ai/code, choisis le dépôt adcloner-eleves et l'environnement AdCloner (icône nuage).
  2. Écris :
Vérifie mon installation AdCloner.

Claude doit répondre que tout est ok. Sinon, il te dit quelle étape refaire : utilise « Retour » pour y revenir.

Terminé 🎉

Bravo , AdCloner est prêt

Pour traduire une pub :

  1. Dépose la vidéo dans le dossier sources de ton dépôt GitHub : Add file → Upload files → Commit changes (25 Mo max).
  2. Sur claude.ai/code (dépôt adcloner-eleves, environnement AdCloner), écris par exemple :
Traduis la vidéo sources/ma-pub.mp4 en français. Ma marque : …, mon produit : …, mon site : …
  1. Claude t'annonce le coût et attend ton ok.
  2. Environ 15 minutes plus tard, il te donne un lien pour télécharger ta vidéo. Tu peux fermer l'ordinateur en attendant.
Mise à jour : quand ton formateur annonce une nouvelle version, va sur ton dépôt GitHub et clique sur Sync fork → Update branch.
Bon à savoir : ton formateur peut voir tes vidéos, pour t'aider à progresser et améliorer AdCloner. Télécharge-les au fur et à mesure : si ton accès se termine, ta copie est supprimée.

Un souci ?

Claude dit qu'une variable est « MANQUANTE »

Revois l'écran « Les réglages » de ton atelier, puis démarre une nouvelle session.

Erreur 401 ou « invalid api key »

La clé de ce service est fausse. Supprime son secret dans le coffre et ajoute-le à nouveau. ElevenLabs : la clé commence par sk_.

Erreur 402, « insufficient credit » ou quota

Le compte de ce service n'a plus de crédit : recharge-le.

Claude ne voit pas mon dépôt

Refais l'écran « Connecte Claude à GitHub ».

Ma vidéo fait plus de 25 Mo

Réduis-la avant (par exemple avec HandBrake, gratuit), ou demande à ton formateur.
